## Features

- Batch process hundreds of images at once
- JPG quality slider and PNG optimization
- Resize by percentage, exact dimensions, or max width/height
- Preserves originals — outputs to a separate folder
- Drag-and-drop folder support

## FAQ

**Will it overwrite my original photos?**  
Never. Output always goes to a separate folder — originals are never touched.

**Does it support RAW camera formats?**  
Currently supports JPG, PNG, WEBP, and BMP. RAW support is planned.
